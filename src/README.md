## Install
To install the theme you will need to use a discord client that supports custom themes, e.g. [Vencord](https://vencord.dev/), [BetterDiscord](https://betterdiscord.app/)

### Using a theme file
- Download your preferred flavor from https://github.com/dom1torii/VGUICord/tree/main/src.
- Put that file into `themes/` folder of your client.
- Enable the theme in your client.

### Using raw theme link
- Copy link for your preferred flavor:
  - Steam (default) - https://dom1torii.github.io/VGUICord/src/vguicord.theme.css
  - Catppuccin Frappe - https://dom1torii.github.io/VGUICord/src/vguicord-catppuccin-frappe.theme.css
  - Catppuccin Macchiato - https://dom1torii.github.io/VGUICord/src/vguicord-catppuccin-macchiato.theme.css
  - Catppuccin Mocha - https://dom1torii.github.io/VGUICord/src/vguicord-catppuccin-mocha.theme.css
  - Gruvbox - https://dom1torii.github.io/VGUICord/src/vguicord-gruvbox.theme.css
- Paste the link inside online theme import field in your client.

## Settings
To change settings you can either change them straight in the theme file or use QuickCSS if your client supports it.

### Font
\* set to `""` to use default font  
Variable: `--font`  
Possible values: `any`  
Default value: `https://dom1torii.github.io/VGUICord/src/css/main.css`

### Rounded avatars
Variable: `--rounded-avatars`  
Possible values: `true`, `false`  
Default value: `false`

### Rounded server images
Variable: `--rounded-servers`  
Possible values: `true`, `false`  
Default value: `false`

### Enable custom status indicators
Variable: `--custom-status`  
Possible values: `true`, `false`  
Default value: `true`

### Enable custom scrollbar
Variable: `--custom-scrollbar`  
Possible values: `true`, `false`  
Default value: `true`

### Display Steam logo
Variable: `--steam-logo`  
Possible values: `true`, `false`  
Default value: `true`

### Disable avatar decorations
Variable: `--disable-avatar-deco`  
Possible values: `true`, `false`  
Default value: `false`

### Disable nameplates
Variable: `--disable-nameplates`  
Possible values: `true`, `false`  
Default value: `false`

### Disable profile effects
Variable: `--disable-profile-effects`  
Possible values: `true`, `false`  
Default value: `false`

### Disable profile frames
Variable: `--disable-profile-frames`  
Possible values: `true`, `false`  
Default value: `false`
